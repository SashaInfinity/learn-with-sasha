## Conversation page — UI polish pass (everything, no overhaul)

Direction confirmed: polish the current slate/amber look across **all four zones** (chat messages & input, sessions sidebar, mascot card, dashboard header), using the existing `--lws-*` tokens and shared classes. No new visual language, no palette changes, no new dependencies. Goal: tighter spacing, consistent surfaces, smoother motion, better hierarchy.

---

### Guiding principles

- **Consume tokens, not literals.** Replace hardcoded `shadow-sm`/`rounded-xl`/`bg-amber-500` in the chat area with `--lws-shadow-*`/`--lws-radius-*`/`--lws-amber` via shared classes. Stops the dashboard drifting from the landing's polish.
- **Fix the one layout rough edge:** the hardcoded `h-[650px]` panels → viewport-relative `calc(100vh - header - margins)` so the chat fills the screen on large monitors and doesn't get cut off on short laptops.
- **One shared easing set** (already in place via `--lws-dur-*`/`--lws-ease`); apply `.lws-lift`/`.lws-rise`/`.lws-message-in` where motion is currently ad-hoc or missing.
- **Reduced-motion** keeps working: all new motion reuses the existing token-driven classes, which the global `prefers-reduced-motion` override already neutralizes.
